VP 3.14.1

चतुर्थदशोऽध्यायः और्वः- ब्रह्मेन्द्ररुद्रनासत्यसूर्याग्निवसुमारुतान् । विश्वेदेवान्पितृगणान्वयांसि मनुजान्पशून् ॥१॥

Aurva: As a part of the uttara kriyaa, what is done is told here. Shraaddha is that which is done with a lot of shraddhe, a lot of devotion. If one does the shraaddha kaaryaas with such devotion, he is going to please all the beings. They are Brahma, Indra, Rudra, Ashvini devaas, Soorya, Agni, Vasu, Marudganaas, Vishve devaas, Pitru ganaas, all the birds, humans, animals, ...
